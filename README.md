# 🏥 Hospital Management System (MERN Stack)

A full-stack **Hospital Management System** built using the **MERN stack**.  
This project provides separate panels for **Admin, Doctors, and Patients** with secure authentication and real-world features.

---

## 🚀 Features

### 👨‍⚕️ Admin Dashboard
- Secure admin authentication (JWT + Cookies)
- Add new doctors
- Add new admins
- View all doctors
- Manage messages & appointments
- Protected routes with role-based access

### 🧑‍⚕️ Doctor Module
- Doctor profile with avatar (Cloudinary)
- Department-based doctor listing
- Secure login

### 🧑‍💻 Patient Module
- Patient registration & login
- Book appointments
- View personal details
- Secure authentication

### 🔐 Authentication & Security
- JWT-based authentication
- HttpOnly cookies
- Role-based authorization (Admin / Doctor / Patient)
- CORS configured for production (Vercel)

---

## 🛠 Tech Stack

### Frontend
- React (Vite)
- React Router DOM
- Axios
- Context API
- React Toastify

### Backend
- Node.js
- Express.js
- MongoDB & Mongoose
- JWT Authentication
- Cloudinary (Image Upload)
- Express File Upload
- CORS

### Deployment
- Frontend: **Vercel**
- Backend: **Vercel (Serverless)**
- Database: **MongoDB Atlas**
